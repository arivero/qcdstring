# Glossary: 1974 name, later name, meaning

| 1974 | Later | Meaning |
|---|---|---|
| dual resonance model, dual model | (bosonic) string theory | The Veneziano amplitude and its operator formalism; a relativistic string. |
| dual-tube model, Shapiro-Virasoro model | closed string | The closed-string sector; its leading trajectory has intercept 2 in flat d = 26. |
| dual Pomeron | Pomeron; Reggeised graviton in holography | The vacuum-exchange trajectory; the closed string's leading trajectory. |
| Neveu-Schwarz-Ramond model | superstring (RNS formalism) | String with worldsheet fermions; tachyon removed by the GSO projection in 1976. |
| Chan-Paton factor | D-brane gauge index | Flavour label carried by the string endpoint. |
| critical dimension | same; or the coefficient of the (26-d) worldsheet term | d = 26 (bosonic), 10 (RNS): where flat-space Lorentz invariance holds exactly. |
| zero-point energy of the transverse modes | Luscher term, Casimir energy | -(d-2)/24 per unit, -pi(d-2)/(24R) for a string of length R with fixed ends. |
| planar diagrams, 1/N expansion | genus expansion, g_s = 1/N | 't Hooft's topological organisation of gauge-theory diagrams. |
| area law, Wilson loop | confining string | exp(-sigma x Area) for a large loop; sigma is the string tension. |
| strong-coupling expansion | same | Wilson's expansion in beta; the Wilson surface is flat and pinned. |
| (no name) | roughening transition | Coupling beyond which the Wilson surface fluctuates freely; the 1/R term appears. |
| (no name) | Creutz ratio | chi(R,T) = -ln[W(R,T)W(R-1,T-1)/(W(R,T-1)W(R-1,T))], a local estimate of sigma a^2. |
| Regge slope alpha' | string scale, l_s^2 | alpha' = 1/(2 pi sigma); 0.88 GeV^-2 for hadrons. |
| string tension sigma | same | Energy per unit length; about 0.18 GeV^2 = 0.9 GeV/fm. |
| Hagedorn temperature | same; string's limiting temperature | sqrt(3 sigma/(pi(d-2))) for the Nambu-Goto string. |
| (no name) | Arvis formula, Nambu-Goto spectrum | E_n(R) = sqrt(sigma^2 R^2 + 2 pi sigma(n - (d-2)/24)). |
| (no name) | effective string theory | Polchinski-Strominger: the long string in any d as an effective field theory. |
| conformal factor of the worldsheet metric | Liouville field; holographic radial coordinate | The extra coordinate of a string in d < 26; the size or energy scale. |
| Wilson's renormalisation-group scale | holographic radial coordinate | Same object seen from the gauge theory. |
| g^2 N | 't Hooft coupling lambda | Fixed as N grows; large lambda means weakly curved string background. |
| counting rules | same; hard scattering in gauge/string duality | dsigma/dt ~ s^{2-n}; from a warped string, the exponent is the total twist. |
| twist | same | Dimension minus spin of an operator; the number of constituents at leading twist. |
| gluonium | glueball | Bound states of gluons; closed strings. |
| (no name) | k-string | String between sources of N-ality k; tension near the sine law. |
| (no name) | Casimir scaling | sigma_R proportional to C_2(R) at intermediate distances. |
| (no name) | worldsheet axion | The pseudoscalar on the 4d flux tube, mass ~1.85 sqrt(sigma). |
| (no name) | TTbar deformation | The worldsheet phase exp(i s/(4 sigma)) as a deformation of free bosons. |
| infinite-momentum frame | light-cone gauge, light-front | Frame in which the string's transverse modes are the only physical ones. |
| A2(1310), g(1680), h(2040) | a2(1320), rho3(1690), a4(1970) | Members of the rho trajectory. |
| f(1270), f'(1514), B(1235), A3(1640) | f2(1270), f2'(1525), b1(1235), pi2(1670) | Other 1974 meson names. |
| F15, F37, H19, H3,11 | N(1680), Delta(1950), N(2220), Delta(2420) | Partial-wave names of baryon resonances. |
| Cornell potential | same | V(r) = -kappa/r + sigma r for heavy quarks; 1975. |
| bag model | same | The MIT competitor; the string is its long, thin limit. |
