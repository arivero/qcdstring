# 023. Gravity-free strings: little strings and NCOS as existence controls
**Status:** open. Scaling checks done by the second line; amplitude checks proposed.
**Depends on:** none
**Predictions:** none registered
**Second line:** T02, T07, T08

## Claim
The thesis argues that the hadronic string is a gauge-theory flux tube.
A separate and stronger question is whether any finite-tension
interacting string theory can exist with gravity removed. Two limits from
the memory say yes in specific settings: little string theory on
NS5-branes, and noncommutative open string theory (NCOS). They describe
no hadrons. They refute the universal statement that strings must carry
dynamical gravity, which is the premise of the 1974 gravity proposal.

## Known in 1974
* Open strings at one loop contain closed strings (Lovelace 1971; the
  nonplanar annulus). This is the 1974 form of the obstruction.

## What the memory says
* Seiberg 1997, Aharony 1999 review: NS5-branes with g_s to 0 at fixed
  alpha' leave an interacting six-dimensional theory with string
  excitations and no gravity.
* Seiberg-Susskind-Toumbas 2000, Gopakumar-Maldacena-Minwalla-Strominger
  2000: in a near-critical electric field the open strings keep finite
  effective tension and coupling while G_10/alpha'_eff^4 scales as
  G_o^4 delta^3; in the nonplanar annulus the usual closed-string poles
  disappear.

## Expected outcome, and what would refute it
An interacting open-string theory whose closed channel has no physical
graviton pole in the limit. Refuted for a given limit if g_s to 0 removes
every retained interaction, or if wound closed strings survive after
compactification.
