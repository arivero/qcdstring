# data

`regge_1974.tsv`: leading Regge trajectories as they can be read from the
April 1974 Review of Particle Properties, with 1974 names and the names
used later. Masses in GeV. `status` is `firm` for entries established in
1974 and `tentative` for states that are either poorly established now
or known only from the memory; `pool` marks the entries used for the
universal-slope estimate (natural-parity leading trajectories, firm
states only). `L` is the orbital angular momentum assigned in the
quark-model (meson: J = L + 1 on the leading natural-parity trajectory;
baryon: J = L + 1/2 for N, Lambda and L + 3/2 for Delta).

The values were written down from memory of the tables and rounded.
Before any of these numbers go into a paper, check them against the
scanned 1974 edition (Phys. Lett. B50, 1).

Columns: trajectory, sector, name_1974, name_now, J, P, L, mass, dmass,
width, status, pool, note.
